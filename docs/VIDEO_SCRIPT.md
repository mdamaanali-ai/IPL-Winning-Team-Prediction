# InternPe Week 3 Video Script

### 0:00–0:15 — Hook
“Can machine learning predict which IPL team is more likely to win before a
match starts? I built an IPL Winning Team Prediction system to find out.”

### 0:15–0:40 — Problem
“The goal is not to use the final score or post-match information. The model
uses pre-match signals such as team history, recent form, head-to-head record,
venue performance and the toss.”

### 0:40–1:10 — Machine Learning
“I compared Logistic Regression, Decision Tree and Random Forest. The target
is simple: does Team 1 win or Team 2 win?”

### 1:10–1:40 — Feature Engineering
“I created sequential historical features so statistics for a match come only
from earlier matches. This helps reduce data leakage.”

### 1:40–2:20 — Demo
“I select two teams, toss winner, toss decision, venue and city. The application
produces a predicted winner and win probability for both teams.”

### 2:20–2:45 — Evaluation
“I also included accuracy, precision, recall, F1 score, confusion matrix and
feature importance.”

### 2:45–3:00 — Closing
“This project helped me apply classification, feature engineering, model
evaluation and Streamlit to a real-world sports prediction problem.”
